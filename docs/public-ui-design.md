# 公共页面视觉规范

2026-10-10 调整系统 A 的公共首页、陪玩目录、服务保障与登录弹窗。业务范围和订单流程仍以 `system-a.md` 为准。

## 设计依据

- [Taste Skill](https://github.com/Leonxlnx/taste-skill/tree/main/skills/taste-skill)：已有产品的视觉改版，保留品牌、导航、路由和业务内容，减少重复色块、装饰与模糊文案。
- [Vercel Web Design Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)：补充键盘焦点、标题层级、可点击区域、表单与响应式检查。通过 Codex skill-installer 安装到本机 skill 目录，不作为项目运行依赖。
- 原生 CSS 与现有组件继续使用，不引入新的前端框架。视觉变化强度 5、动效强度 2、信息密度 4；动效仅用于交互反馈，并尊重减少动态效果设置。

## 样式约定

- 浅灰页面、白色业务内容，深色摄影首屏；品牌紫色 `#5652c7` 只用于操作和选中状态。
- 正文 `#24262e`，辅助文字 `#656976`；价格使用等宽数字。
- 内容宽度最多 1240px，服务卡片 10px 圆角，按钮和输入框 6px，头像保持圆形。
- 首页先展示服务与价格，再展示在线空闲陪玩，招募入口放在其后。无空闲陪玩时引导浏览目录，不伪造在线人数、评价或服务单量。
- 公共页面增加跳至内容入口；订单类型筛选重绘后保留焦点；装饰图标不进入辅助阅读；页脚客服入口复用原有登录和客服流程。
